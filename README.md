# paper-logic-view：把论文的论证逻辑画在 PDF 原文上

给它一篇论文 PDF，它在原文上标出每句话在论证里的角色，再用箭头连出"谁撑谁"。不推动论证的句子会被调暗，断掉的地方自动列成问题清单，点一下就跳到原文。

结果是**一个 HTML 文件**：双击就能打开，手机上也能看，也可以直接发布成网页。

两种用法：

- **读**：读别人的论文，一眼看出主线怎么走。
- **查**：查自己的草稿，找出逻辑断在哪里。

## 它查什么

**A 档：画出箭头图后，页面自己算**

| 问题 | 意思 |
|---|---|
| 坑没填 | 重要的结论没有任何东西撑它；或者提出的问题、许下的承诺，后文没有回答 |
| 跳帧 | 两句之间要补一句作者没写的话才连得上；或者理由在前、结论在后，中间隔了好几页 |
| 空转 | 同一栏里一大段文字不推动论证 |
| 空中楼阁 | 主线结论往回追，追到底也落不到证据上，只是主张撑主张 |
| 循环论证 | 支撑关系连成了环 |
| 孤立证据 | 一条证据没有撑任何东西 |

**B 档：模型判断，页面列出来**

| 问题 | 意思 |
|---|---|
| 说过头 | 结论的口气比证据大 |
| 隐含前提 | 推理要成立，得先默认一件没写出来的事 |
| 替代解释 | 结果还可能是别的原因造成的，作者没排除 |
| 前后打架 | 两处说法互相矛盾 |
| 先用后定义 | 术语在定义之前就用上了 |

另外，原文引用在 PDF 里找不到的标注会单独列成"没定位上"，不会悄悄丢掉。

它**只画结构**，不打分，也不给改稿意见。要审稿意见，用审稿类工具（比如同系列的 paper-review）。

## 怎么用

这是一个 skill，Claude Code、Cursor、Codex 这类 code agent 都能用。

1. 把 `skill/paper-logic-view/` 整个目录拷到你的 agent 读 skill 或规则的地方。比如 Claude Code 放到 `~/.claude/skills/`；其他 agent 放进项目目录，再在对话里让它读 `SKILL.md`。
2. 对 agent 说："用 paper-logic-view 把这篇论文的逻辑画出来"，或者"帮我查查这份草稿的逻辑"，再附上 PDF。
3. agent 会读论文、填一份 JSON、跑校验、打包，最后给你一个 HTML。

判断（挑句子、定类型、连箭头）由你在用的那个模型来做。脚本只用 Python 标准库，不调任何 API，你的论文不会被上传到任何地方。

读 PDF 文字需要下面任意一个：`pdftotext`（poppler 带的，macOS 上 `brew install poppler`）、`pypdf`、`pdfminer.six`。

## 手动跑

```bash
cd skill/paper-logic-view
python3 scripts/pdf_text.py 论文.pdf -o 论文.txt          # 1. 按页抽文字，给模型读
# 2. 让模型按 reference/fill-guide.md 填 logic.json
python3 scripts/check_logic.py 论文.pdf logic.json       # 3. 校验：引用能不能在 PDF 里找到
python3 scripts/pack_logic.py 论文.pdf logic.json -o 论文_逻辑图.html   # 4. 打包
```

## 页面上能做什么

- **调暗**滑条：没标注的部分调暗多少。
- **只看主线**：只留最重要的那几句和它们之间的箭头。
- **原页 / 重排**：原页是 PDF 原样加高亮和箭头；重排把标注按顺序排成卡片，左边画成弧线图，手机上默认用这个。
- **连线**：悬停时显示、全部显示，或者关掉。
- **详情**：在高亮旁边显示类型小标签。
- 浅色、深色两种模式；深色模式下 PDF 页面可以反色。
- 点图例可以隐藏某一类标注。
- ⚙ 里可以调"跳帧"的距离阈值。

## 演示

`demo/` 里是一组改前、改后的对比，用的是编出来的"共享单车需求预测"草稿：

- `demo_before.html`：改前。查出 4 处坑没填、2 处跳帧、1 处空转、2 处说过头、1 个隐含前提。
- `demo_after.html`：改后。同样的箭头图，问题清单清零。

草稿的源文件在 `demo/src/`（HTML，用 Chrome 打印成 PDF），标注数据是 `demo/before.json` 和 `demo/after.json`。

## 原文定位是怎么做的

PDF.js 把每页的文字块拼成一条流，引用和原文两边做同样的归一化：NFKC（把 ﬁ 这类连字拆开）、转小写、去掉所有空格和标点。这样连字符断行（`predic-` + `tion`）、跨行、跨栏、跨页都能对上。先在标注写的那一页找，再找前后一页，最后找全文。还找不到时，用开头、中间、结尾的片段做近似匹配，画成虚线框，并列在"近似定位"里。

校验脚本用同一套规则预先查一遍，所以打包前就知道哪些引用对不上。

## 发布

打包出来的 HTML 只从 cdnjs 加载 PDF.js（版本写死为 3.11.174），不请求别的地址，单个文件不超过 16 MB，可以直接作为 claude.ai artifact 或任何静态网页发布。PDF 本身大约要小于 11 MB。
