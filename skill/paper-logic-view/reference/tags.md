# 标签、连线、检查规则

## 标签类型（annotation.type）

| type | 页面显示 | 在论证里干什么 | 例子 |
|---|---|---|---|
| `claim` | 主张 CLAIM | 作者要读者相信的话：结论、贡献、判断 | "我们的方法在长序列上更稳定。" |
| `evidence` | 证据 EVIDENCE | 实验结果、数据、图表、证明、引用的事实数据 | "表 2 中误差下降了 18%。" |
| `method` | 方法 METHOD | 作者做了什么、怎么做 | "我们用滑动窗口切分轨迹。" |
| `definition` | 定义 DEFINITION | 引入术语或记号 | "我们把 X 称为'冷启动站点'。" |
| `assumption` | 前提 ASSUMPTION | 没证明、默认成立的条件 | "假设用户行为在一周内平稳。" |
| `problem` | 问题 PROBLEM | 挖的坑：现有方法哪里不够、要回答的问题、"我们将展示……"这类承诺 | "现有方法无法处理新站点。" |
| `background` | 背景 BACKGROUND | 已知事实、别人的工作 | "Transformer 已广泛用于时序预测。" |
| `limitation` | 局限 LIMITATION | 作者承认的边界和不足 | "我们只在一个城市的数据上做了验证。" |

没标的句子就是"不推动论证"，页面会按亮度滑条把它们调暗。

## 重要度（annotation.importance）

- **3 主线**：拿掉它，论文就不成立。一般是核心问题、核心方法、主要结论和撑它们的关键实验。整篇通常 5–15 条。
- **2 支撑**：撑主线的中间环节。
- **1 次要**：交代性的、可有可无的。

"只看主线"开关只显示重要度 3 的标注，以及它们之间的箭头。

## 连线类型（link.type）

方向一律是 **from 撑 to**：from 是理由，to 是被撑的话。

| type | 页面显示 | 含义 | 必填 |
|---|---|---|---|
| `supports` | 支撑（实线） | from 直接推出或证明 to | — |
| `indirect` | 间接（虚线 + ⚠） | 能连上，但中间缺一步 | `missing_step` |
| `answers` | 填坑（实线，空心箭头） | from 回答了 to 这个 problem | — |
| `qualifies` | 限定（点线） | from 给 to 加条件、划边界 | — |
| `conflicts` | 打架（红色双向线） | from 和 to 互相矛盾：数字对不上、术语前后意思不同、局限推翻了结论 | 建议填 `note` |

连线上还可以加两个判断，不改变连线类型：
- `overreach`：说过头。证据只覆盖了什么，结论却说了什么。
- `alternative`：替代解释。这个结果还可能是别的原因造成的，作者没有排除。

## 检查规则

页面打开时自动计算，列在左侧的"问题清单"里，点一条就跳到原文。校验脚本也会算 A 档里除了"空转"以外的几条。

### A 档：页面根据箭头图自己算

| 规则 | 判定 |
|---|---|
| **坑没填** | 重要度 ≥ 2 的 `claim` 没有任何 `supports` / `indirect` 箭头指向它，也没写 `external`；或者 `problem` 没有任何 `answers` 箭头指向它（"我们将展示……"没兑现也算在这里）。只靠 `external` 撑的结论单列成"只靠引用"，作提醒用。 |
| **跳帧** | 任何 `indirect` 连线；或者一条 `supports` 的理由在前、结论在后，而且隔得太远：默认跨了 ≥ 3 页（也可以设成中间夹了 ≥ N 条标注，默认不看这一条，因为标注密的时候容易误报），读者得把前面的理由一直记到后面。结论在前、证据在后（比如引言先说贡献，实验章节再给数据）是正常的先挖坑后填坑，不算。两个阈值都能在页面上调。 |
| **空转** | 同一栏里，连续一大段文字没有重要度 ≥ 2 的标注，高度超过半栏、至少 8 行。参考文献之后的内容、图表说明、脚注不算。 |
| **空中楼阁** | 从重要度 3 的 `claim` 沿 `supports` / `indirect` 往回追，追到底也找不到 `evidence`，也没有写了 `external` 的标注。等于主张撑主张，没落到证据上。 |
| **循环论证** | `supports` / `indirect` 连成了环。 |
| **孤立证据** | `evidence` 没有撑任何东西：没有从它出发的连线。 |

### B 档：模型判断，标在数据里，页面列出来

| 规则 | 来自哪里 |
|---|---|
| **说过头** | 连线上的 `overreach` |
| **隐含前提** | `implicit: true` 的 assumption |
| **替代解释** | 连线上的 `alternative` |
| **前后打架** | `conflicts` 连线 |
| **先用后定义** | `definition` 的 `first_used_page` 比它所在的 `page` 早 |

### 没定位上

`quote` 在 PDF 里找不到的标注单独列一组，显示引用原文，不会悄悄丢掉。近似定位到的会画成虚线框，也列出来，方便核对。
